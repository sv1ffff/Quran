# Holy Quran Web Application 📖


[![Live Demo](https://img.shields.io/badge/🌐%20Live%20Demo-qurvn.netlify.app-blue?style=for-the-badge)](https://qurvn.netlify.app/)

A premium, minimalist digital experience for reading and listening to the Noble Quran. This project was designed with a focus on high-end aesthetics, accessibility, and a distraction-free user experience.

---

## ✨ Features

- **🎯 Modern & Minimalist UI**: A clean, editorial-style interface designed for focus and tranquility.
- **🔍 Advanced Search**: Intelligent search engine that works seamlessly with and without Arabic diacritics (Tashkeel).
- **🔊 Audio Recitations**: Listen to your favorite reciters while reading.
- **📜 Auto-Scroll**: A smooth reading experience with adjustable auto-scroll speed.
- **🌓 Dark & Light Modes**: Beautifully optimized themes for all lighting conditions.
- **📱 Responsive Design**: Fully functional across all devices, from mobile to desktop.
- **🌍 Multi-language Support**: Arabic, English, and French translations available.

---

## 🚀 Technology Stack

- **[React.js](https://reactjs.org/)**: Core framework for a fast, component-based architecture.
- **[Tailwind CSS](https://tailwindcss.com/)**: For a modern, utility-first design system.
- **[Framer Motion](https://www.framer.com/motion/)**: Delivering smooth, premium micro-interactions and animations.
- **[Redux Toolkit](https://redux-toolkit.js.org/)**: Efficient state management for language and theme settings.
- **[Al Quran Cloud API](https://alquran.cloud/api)**: Reliable data source for Quranic text and metadata.

## 🛠️ Installation & Setup

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sv1ffff/Quran.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd holy
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm start
   ```
